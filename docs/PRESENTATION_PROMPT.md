# Presentation-Generation Prompt

The event needs **no formal slides** — judging is a **3-minute live product demo + 2-minute Q&A** (see `DEMO_RUNSHEET.md`). Slides are *optional support*, and a **tech-setup diagram is explicitly encouraged**. So this prompt builds a **lean ~10-slide backing deck** that reinforces the live demo — not a wall of text. Paste the block below into an AI slide generator (Gamma / Tome / Claude "make me a deck"); tell it **not to invent numbers** and to keep every slide to a headline + 3–5 tight bullets + one visual.

---

You are an expert pitch-deck designer. Generate a **lean 10-slide support deck** for the **in-person 3-minute demo** of an AI trading system, **Quanthack — SIGNAL//LAYER**. Audience: **technical judges**. The deck *supports a live product demo* — it is not the pitch itself, so favor one strong idea + one visual per slide. Tone: **confident, precise, honest**. Visual style: **dark "fintech terminal"** — near-black bg, single chartreuse/lime accent; **model brand colors: Claude = orange, NVIDIA Nemotron = green, DeepSeek = blue**; monospace for data; clean diagrams/timelines, no clip-art. Use ONLY these facts (don't invent numbers):

**JUDGING — build every slide to score on these (4 × 25%):** **Future Potential** (long-term growth/impact; *how they evaluate quality & consistency of the outcome*) · **P&L Placement** (does it work / is it implemented well) · **Creativity / Uniqueness** (is the concept novel) · **Pitching Quality**. Only 25% is raw P&L — so **lead with creativity (AI-native) + future potential (self-grading & honest validation)**, not a P&L curve.

**One-liner:** An AI-native autonomous trading system where a frontier LLM (Claude Opus 4.8, `claude-opus-4-8`) *is* the strategy — it decides direction + calibrated conviction, a blind multi-model ensemble cross-checks every call, the system grades its own models by asset category over time, and a deterministic risk floor no model can breach makes blow-up structurally impossible.

**Models — use these EXACT names/ids wherever models are shown:** primary decider = **Claude Opus 4.8** (`claude-opus-4-8`, Anthropic); blind voters = **NVIDIA Nemotron-3-Super-120B** (`nvidia/nemotron-3-super-120b-a12b`, NVIDIA NIM) and **DeepSeek-V4-Pro** (`deepseek-ai/DeepSeek-V4-Pro`, live via the Pydantic AI Gateway → Doubleword); cheap backtest model = **DeepSeek-V4-Flash** (`deepseek-ai/DeepSeek-V4-Flash`).

**Context:** multi-day simulated competition; ~14 instruments across forex, metals, crypto; $1,000,000 capital; up to 1:30 leverage; **liquidation = instant elimination**.

**What sets it apart (the spine — this is the Creativity story):** the common move is to keep the LLM as an advisory *narrator* bolted onto a classical statistical strategy (pairs / cointegration / conformal). We do the opposite — the **LLM is the decision-maker** — and the real contribution is the architecture that makes that safe and accountable: (1) a **blind three-model ensemble** that independently cross-checks every call; (2) the system **grading its own models, by asset category, over time**; (3) a **hard risk floor the AI can never breach**. We chose this *after* building and backtesting classical strategies (momentum, mean-reversion, stat-arb, order-flow) — none had durable edge after costs.

**What we feed the LLMs:** NOT raw candles — a distilled, token-cheap **multi-timeframe snapshot**, one line per instrument: last price; returns 1h/4h/1d/3d; trend up/down on M15/H1/H4 (EMA cross); a momentum z-score; per-bar volatility; price's position in its ~5-day range. Example: `EURUSD: px=1.084 | ret 1h=+0.03 4h=-0.12 1d=+0.21 3d=+0.55% | trend M15=up H1=up H4=dn | mom_z=+0.8 vol/bar=0.04% | 5d-range=62%`. **All three models get the identical SYSTEM prompt + snapshot** (full transparency — shown live in the "Context Control" page). They return per instrument: `direction (long/short/flat)`, `confidence ∈ [0,1]`, a one-line rationale + a one-line regime narrative ("Market Read"). Only Claude is Pydantic-schema-validated; the voters are parsed as strict JSON and dropped if malformed — a hallucination can never reach trade logic. We do NOT feed: raw ticks, order book, account state, news, or one model's answer to another.

**Two cadences:** **every ~5s (tick loop):** assess risk FIRST (kill-switch can flatten before strategy runs) → reconcile toward targets only when the signal changed → guarantee a broker stop on every position → ratchet trailing stops → run the gated scalper last. **Every 15 min (AI refresh):** re-query all three models, merge consensus, form new targets (operator can force an immediate refresh; the panel live-updates ~1s). On AI failure it backs off 30s→…→300s and degrades to Claude-only. **The LLM never needs to be fast — judgment is slow, safety + execution are continuous deterministic code.**

**Decision pipeline (one slide):** 1) Risk first (margin <150% → flatten, stop). 2) Build the snapshot. 3) Claude → direction + calibrated confidence + regime (always authoritative on direction). 4) Two **blind** voters (Nemotron, DeepSeek-V4-Pro live via the Pydantic AI Gateway) rate the same snapshot without seeing Claude. 5) Consensus merge — agreeing voters only *raise* confidence (`combined = cc + (1−cc)·0.5·mean(agreeing)`); never flip/veto. 6) Size via the `aggression` dial (leverage ~2×→6×, conf¹→conf²·⁵, risk-parity→conviction). 7) Reconcile only the delta; attach the broker stop. 8) Log everything (JSONL + Markdown).

**Self-grading (the Future-Potential centerpiece):** the system grades its OWN models — per-model **directional hit-rate by asset category (FX / Metals / Crypto) over time**, vs a 50% coin-flip baseline, in a live **Model Accuracy** page. So edge is *measured, not assumed* — and the panel shows a measurable lift on metals while efficient FX sits near coin-flip. Backtesting is real and cheap: the AI signal was backtested through the Pydantic AI Gateway → Doubleword for **≈$0.29 vs ~$22 live (98.7% cheaper)**, with the aggression dial swept 0→1 (drawdown-capped at every level, no blow-up).

**Risk cage (blow-up is structurally impossible):** kill-switch flattens all at 150% margin level (contest stop-out is 30%); leverage cap; margin cap; trailing-peak graduated drawdown de-risk; a guaranteed broker stop on every position within one tick. Risk runs FIRST every tick — AI and human can't override it.

**Honest validation + live post-mortem (Future Potential — "how do you evaluate quality & consistency"):** we ran a full post-mortem on real trade history. **The safety floor held — no liquidation.** The losses we did take came from risk *shaping*, not the floor or model direction: stops sized in **% not $** (so a single volatile-name trade could lose too much), **oversizing** in high-vol instruments, and a **profit giveback** that our coarse drawdown ladder didn't catch early. We *measured* all of it and the roadmap is concrete: a **per-trade $-risk budget**, **vol-scaled (ATR) stops**, and **finer drawdown rungs**. (Honesty note for the speaker: present this as rigor — we grade ourselves and know exactly what to tighten next; the cheap backtest model shows ~coin-flip, so the live edge rests on the frontier model + ensemble, which is why self-grading exists.)

**Integrated scalper:** crypto fast-momentum (alts confirmed by a BTC lead-lag) on ≤2 operator-assigned symbols; **gated by a walk-forward backtest** (only goes live if it clears out-of-sample); per-symbol arming; fully isolated so it can never crash the engine.

**Operator console (SIGNAL//LAYER):** a bespoke live dashboard — equity vs risk floor, currency-strength ribbon, consensus over-time heatmap (Claude/Nemotron/DeepSeek/Combined), a "Market Read" of all three regime narratives, the **Model Accuracy** page (hit-rate by category over time), a **Context Control** page (exactly what each model is fed), a **Volatility** page, per-symbol projection cones, the open position with **draggable SL/TP lines**, candle/line + 1m/15m/1h/4h/1d toggles with years of deep history; steering — aggression/presets, panic-flatten, manual refresh, scalper assign→gate→arm, human overrides. Read-only by default; cannot weaken the risk floor.

**Tech stack (include a clean architecture/data-flow diagram — encouraged by the judges):** Python 3.13 · Claude **Opus 4.8** (`claude-opus-4-8`) · NVIDIA **Nemotron-3-Super-120B** (`nvidia/nemotron-3-super-120b-a12b`) · **DeepSeek-V4-Pro** (`deepseek-ai/DeepSeek-V4-Pro`) live via the Pydantic AI Gateway → Doubleword (same gateway powers ~98.7%-cheaper backtesting on **DeepSeek-V4-Flash**, `deepseek-ai/DeepSeek-V4-Flash`) · MetaTrader 5 · FastAPI + Uvicorn · Plotly.js · Pydantic v2 · NumPy/pandas/PyArrow · httpx.
